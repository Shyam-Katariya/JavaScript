# JavaScript Learning Repository

A collection of hands-on JavaScript examples and practice exercises, organized by language concept. The repository covers foundational syntax, data structures, browser DOM work, APIs and object-oriented JavaScript.

## Topics

| Directory / file | Topics |
|---|---|
| `Basic/` | Objects, loops and iteration |
| `Array/` | Array fundamentals and operations |
| `String/` | String handling examples |
| `String Oparator/` | String operator practice |
| `DOM/` | HTML documents and DOM manipulation |
| `OOPS/` | Objects, classes, `call` and `bind` |
| `Api/` | API-related practice |
| `data-type.js` | JavaScript data types |
| `demo.js` | General practice examples |

## Run examples

Most JavaScript files can be run with Node.js:

```bash
node data-type.js
node Basic/loops.js
node Array/Arrays.js
```

Browser-focused examples in `DOM/` and some `OOPS/` files should be opened in a web browser.

## Suggested learning path

1. Data types and variables
2. Conditions, loops and iteration
3. Strings, arrays and objects
4. Functions and object-oriented concepts
5. DOM manipulation
6. APIs and asynchronous JavaScript

## Purpose

This repository is a growing practice notebook. Examples are kept small and focused so individual concepts can be explored and revisited.
